# Диспетчер

**Диспетчер** — универсальная модульная платформа диспетчеризации и управления оборудованием.

Проект строится вокруг небольшого ядра и устанавливаемых расширений. Ядро предоставляет универсальные механизмы работы с проектами, Dashboard, мнемосхемами, устройствами, метриками, командами, событиями, пользователями и пакетами. Дополнительные возможности — автоматизация, история, CCTV, СКУД, конкретные протоколы и другие предметные функции — подключаются как плагины.

## Текущий этап

Сейчас зафиксирована концепция ядра на уровне продукта и пользовательских сервисов. Архитектура, технологии и внутреннее устройство системы намеренно пока не определяются.
