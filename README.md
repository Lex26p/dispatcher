# «Диспетчер»

Репозиторий продуктовой концепции и функциональной спецификации универсальной модульной SCADA-платформы «Диспетчер».

Общая горизонтальная концепция завершена и прошла три независимые сквозные проверки. Текущий рабочий этап — **функциональная спецификация**: детализация наблюдаемого поведения продукта перед системной архитектурой.

## Начало работы

1. [`AGENTS.md`](AGENTS.md) — обязательные правила работы.
2. [`docs/project/PROJECT_STATE.md`](docs/project/PROJECT_STATE.md) — текущий этап и точка продолжения.
3. [`docs/product/PRODUCT_CONCEPT.md`](docs/product/PRODUCT_CONCEPT.md) — каноническая общая концепция.
4. [`docs/product/PRODUCT_DECISIONS.md`](docs/product/PRODUCT_DECISIONS.md) — действующие решения `PRD-Q001–PRD-Q803`.
5. [`docs/functional/README.md`](docs/functional/README.md) — правила нового функционального этапа.
6. [`docs/functional/ROADMAP.md`](docs/functional/ROADMAP.md) — временная дорожная карта: сделано / осталось / зависимости.
7. [`docs/functional/REFERENCE_SCENARIOS.md`](docs/functional/REFERENCE_SCENARIOS.md) — сквозные сценарии проверки требований.
8. [`docs/functional/engineering/ENGINEERING_CONFIGURATION.md`](docs/functional/engineering/ENGINEERING_CONFIGURATION.md) — первая активная функциональная спецификация.

История прежних редакций, аудитов и удалённых служебных файлов остаётся доступна через Git и не дублируется в рабочем дереве.
