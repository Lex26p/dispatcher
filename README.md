# «Диспетчер»

Репозиторий проекта «Диспетчер».

На текущем шаге в репозитории зафиксированы только правила совместной работы и передачи контекста между чатами и моделями. Продуктовые документы, дорожная карта, архитектура и код ещё не добавлены.

## С чего начинать работу

Любой ассистент или участник проекта должен читать файлы в следующем порядке:

1. [`AGENTS.md`](AGENTS.md) — обязательные правила работы ассистента с репозиторием и пользователем.
2. [`docs/project/PROJECT_STATE.md`](docs/project/PROJECT_STATE.md) — текущее состояние и точка продолжения.
3. [`docs/project/INTERACTION_PROTOCOL.md`](docs/project/INTERACTION_PROTOCOL.md) — подробный порядок обсуждения, подготовки архивов и фиксации изменений.
4. [`docs/project/DECISIONS.md`](docs/project/DECISIONS.md) — принятые решения по ведению проекта.
5. [`docs/project/OPEN_QUESTIONS.md`](docs/project/OPEN_QUESTIONS.md) — сознательно оставленные нерешённые вопросы.
6. [`docs/project/AI_WORK_NOTES.md`](docs/project/AI_WORK_NOTES.md) — межтематические заметки и напоминания для продолжения работы.

## Источник истины

Актуальным состоянием проекта считается содержимое ветки `master` репозитория `Lex26p/dispatcher` на последнем полном SHA, подтверждённом пользователем.

Переписка в чате используется для обсуждения, но не заменяет зафиксированные в репозитории документы.
