# Плагин автоматизации — концепция

## Статус

Автоматизация **не входит в ядро**. Это один из первых сервисов, который планируется добавить как официальный плагин после ядра.

Причина: без автоматизации система становится ближе к мониторингу и ручному управлению, но сохраняет базовую работоспособность как диспетчерская платформа.

## Назначение

Автоматизация позволяет системе выполнять действия без постоянного участия оператора.

В концепцию плагина входят:

- визуальные правила и сценарии для типовых инженерных задач;
- полноценный JavaScript для программистов;
- планировщик;
- запуск по событиям;
- запуск по изменениям данных и условиям;
- ручной запуск сценариев;
- возможность одному сценарию запускать другой.

## Визуальная логика и JavaScript

Типовые сценарии должны настраиваться графически. Визуальный редактор не обязан выражать абсолютно любую возможную логику.

Сложная и нестандартная логика реализуется через полноценный JavaScript.

## Планировщик

Планировщик является частью плагина автоматизации, а не отдельным независимым сервисом ядра.

Расписание может запускать команды и сценарии автоматизации.

## Параметры

На текущем уровне концепции не вводится отдельный универсальный механизм «параметров автоматизации» по аналогии с Dashboard и мнемосхемами.

Конкретная автоматизация настраивается на конкретные данные и действия. Массовое создание однотипных сценариев может решаться шаблонами или копированием.

JavaScript сам предоставляет программисту необходимые механизмы повторного использования логики.

## Отключение

Автоматизация должна иметь возможность временно отключаться без удаления настроек.
