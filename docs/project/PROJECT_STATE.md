# Текущее состояние проекта

**Дата состояния:** 6 августа 2026 года.  
**Репозиторий:** `https://github.com/Lex26p/dispatcher`.  
**Ветка:** `master`.  
**Последний подтверждённый SHA:** будет указан пользователем после первого коммита.

## 1. Текущий режим работы

Настраивается воспроизводимый процесс взаимодействия между пользователем и AI-ассистентом.

В этом состоянии созданы только служебные документы, необходимые для:

- передачи контекста между чатами и моделями;
- подготовки изменений ZIP-архивами;
- фиксации решений, вопросов и заметок;
- работы в одной ветке без pull request.

## 2. Что уже согласовано

- Репозиторий является основным источником актуальных данных.
- Работа ведётся в одной ветке `master`.
- Пользователь не редактирует текст и код вручную.
- Ассистент формирует все изменения и передаёт их ZIP-архивом.
- Архив распаковывается в `C:\Projects\dispatcher`.
- Ассистент выдаёт минимальный блок Git-команд.
- Пользователь после `git push` присылает полный SHA нового коммита.
- Концепции будут описывать зрелый продукт целиком, без деления на этапы реализации.
- Обсуждения будут разбиваться на небольшие темы.
- Ассистент будет задавать вопросы, предлагать варианты и рекомендуемый ответ.
- Межтематические заметки будут сохраняться в отдельном файле.

## 3. Что намеренно ещё не сделано

- Не создана дорожная карта.
- Не перенесена продуктовая концепция.
- Не созданы сервисные концепции.
- Не начато проектирование архитектуры.
- Не определён технологический стек.
- Не создан исходный код.

## 4. Активная тема

Активной продуктовой темы нет.

Текущая организационная задача — зафиксировать и закоммитить базовые документы взаимодействия.

## 5. Следующее действие

1. Пользователь распаковывает первый архив.
2. Пользователь выполняет предоставленные Git-команды.
3. Пользователь присылает полный SHA нового коммита.
4. После подтверждения SHA выбирается следующая организационная задача. Дорожная карта не создаётся до отдельного указания пользователя.

## 6. Точка входа для новой модели

Новая модель должна прочитать:

1. `/AGENTS.md`;
2. `/docs/project/INTERACTION_PROTOCOL.md`;
3. `/docs/project/DECISIONS.md`;
4. `/docs/project/OPEN_QUESTIONS.md`;
5. `/docs/project/AI_WORK_NOTES.md`.

После этого необходимо запросить или использовать уже предоставленный пользователем полный SHA актуального коммита и продолжать только от него.
