# Открытые вопросы

**Назначение:** сознательно оставленные без окончательного решения вопросы.  
**Статус:** действующий журнал.

## UX-Q001. Детальная модель редактора дашбордов

**Статус:** открыт.  
**Связанные решения:** `PRD-Q178–PRD-Q193`.

Нужно отдельно определить структуру страницы, вложенность контейнеров, адаптивность, свойства, историю изменений, совместное редактирование, библиотеку шаблонов, ссылки, производительность и UX редактора.

## UX-Q002. Детальная модель редактора мнемосхем

**Статус:** открыт.  
**Связанные решения:** `PRD-Q178–PRD-Q193`.

Нужно определить графические примитивы, соединения, символы, слои, привязки к данным, версии, шаблоны, масштабирование, совместное редактирование и проверку производительности. Редактор полностью отделён от редактора дашбордов.

## UX-Q003. Поведение масштабирования встроенной мнемосхемы

**Статус:** открыт.

Общее направление принято: мнемосхема может масштабироваться колёсиком, но точное поведение зависит от того, занимает она всю страницу или встроена в прокручиваемый дашборд. Конкретные жесты должны быть проверены прототипом.

## PERF-Q001. Количественные профили производительности

**Статус:** отложен.

Состав измеряемых характеристик согласован, но численные пределы следует устанавливать после прототипов, генераторов нагрузки и выбора аппаратных профилей.

## AUT-Q001. Детальная концепция runtime и редактора правил

**Статус:** открыт.  
**Связанные решения:** `PRD-Q194`, `PRD-Q195R–PRD-Q216`.

Нужно отдельно определить точный контракт SCADA API для кода, модель модулей и шаблонов, runtime lifecycle, диагностику, debugging, profiling, developer workflow и взаимодействие с внешними IDE/Git без выбора технологического стека на стадии общей концепции.

## IMP-Q001. Точные текстовые схемы импорта по редакторам

**Статус:** открыт.  
**Связанные решения:** `PRD-Q265N–PRD-Q290N`.

Общая модель строгого атомарного текстового импорта принята. Конкретные колонки, разделители, версии схем и предметные правила каждого редактора определяются в концепции соответствующего сервиса и редактора.
