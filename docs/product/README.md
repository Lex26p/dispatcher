# Продуктовые документы

## Актуальные документы

1. [`PRODUCT_CONCEPT.md`](PRODUCT_CONCEPT.md) — связная промежуточная общая продуктовая концепция.
2. [`PRODUCT_DECISIONS.md`](PRODUCT_DECISIONS.md) — реестр принятых решений от `PRD-Q001` через текущие заменяющие блоки до `PRD-Q304R`.
