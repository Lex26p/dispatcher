# Устройства, метрики и команды

## Устройство

Устройство — универсальный объект диспетчеризации, через который система получает данные и/или выполняет команды.

Устройство не обязано соответствовать одному физическому устройству. Оно может быть виртуальным и объединять данные из разных источников.

Для пользователя не вводится отдельная классификация «физическое/виртуальное» как обязательная часть интерфейса.

## Метрика

Метрика — универсальная единица данных системы.

Метрика может:

- относиться к устройству;
- существовать самостоятельно;
- поступать от оборудования;
- вычисляться из других данных.

Примеры: температура, давление, состояние, CPU, RAM, суммарная мощность, расчётный показатель.

Метрики могут иметь разные типы значений и пользовательское представление значений, единицы измерения и качество данных.

Одна метрика может использоваться в разных устройствах, Dashboard, мнемосхемах, событиях и других частях системы без необходимости создавать копии значения.

## Команда

Команда — отдельное от метрики понятие, представляющее действие, которое система может выполнить.

Команды могут быть простыми или принимать параметры, например Start, Stop, Reset, SetTemperature, SetMode.

Dashboard и мнемосхемы являются способами вызвать команду, но сама команда существует независимо от конкретного интерфейса.

Команда должна иметь понятный результат выполнения, когда это возможно: успешно, ошибка, отклонено, нет связи и т. п.

Для отдельных команд может использоваться дополнительное подтверждение.

## Шаблоны устройств

Шаблоны используются для быстрого создания типовых устройств.

После создания устройство становится самостоятельным. Последующие изменения шаблона не должны автоматически менять уже созданные устройства.

## Общий принцип

Dashboard, мнемосхемы, диспетчер событий и плагины должны работать с универсальными устройствами, метриками и командами, а не зависеть от конкретного типа оборудования.
