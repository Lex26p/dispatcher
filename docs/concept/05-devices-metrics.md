# Устройства и метрики

## Устройство

Устройство — универсальный объект диспетчеризации, объединяющий связанные с ним метрики и описание.

Устройство не обязано соответствовать одному физическому устройству. Оно может быть виртуальным и объединять данные из разных источников.

Для пользователя не вводится обязательная классификация «физическое/виртуальное».

## Метрика

Метрика — универсальная единица данных системы.

Метрика может:

- относиться к устройству;
- существовать самостоятельно;
- поступать от оборудования;
- вычисляться из других данных;
- быть доступной только для чтения;
- разрешать запись для управления оборудованием или состоянием системы.

Примеры: температура, давление, положение клапана, состояние, уставка, CPU, RAM, суммарная мощность, расчётный показатель.

Отдельная универсальная сущность `Command` в ядре не используется. Управление строится через метрики, для которых разрешена запись. Инженер и драйвер определяют, какие значения доступны для записи, не вводя искусственного списка поддерживаемых команд устройства.

Одна метрика может использоваться в Dashboard, мнемосхемах, событиях, плагинах и других частях системы без создания копий значения.

## Состояние метрики

У каждой рабочей метрики имеется связанная метрика состояния.

Рабочая метрика содержит текущее значение, а связанная state-метрика содержит одно актуальное состояние, например:

- Normal;
- Warning;
- Alarm;
- NoData;
- Maintenance.

Точный набор состояний будет утверждаться отдельно.

Диспетчер событий/аварий отслеживает настроенные условия и при необходимости записывает нужное состояние связанной state-метрики.

## Шаблоны устройств

Шаблоны используются для быстрого создания типовых устройств.

После создания устройство становится самостоятельным. Последующие изменения шаблона не должны автоматически менять уже созданные устройства.

## Общий принцип

Dashboard, мнемосхемы, диспетчер событий и плагины должны работать с универсальными устройствами и метриками, а не зависеть от конкретного типа оборудования или заранее заданного набора команд.
